# 📈 Pro Stock Terminal

**Pro Stock Terminal** is a professional-grade stock market analysis dashboard built with Python. It leverages **Streamlit** and **Plotly** to provide interactive financial data visualization, designed to offer traders and investors clean, intuitive, and actionable market insights.

## ✨ Key Features

- **📊 Interactive Candlestick Charts:** High-quality charts powered by Plotly, supporting zooming, panning, and hover-over data inspection.
- **📉 Technical Analysis:** Built-in essential technical indicators to aid decision-making:
    - **Moving Averages:** SMA 20 and SMA 50.
    - **Bollinger Bands:** Dynamic volatility bands.
- **🔊 Volume Analysis:** Integrated volume bars at the bottom of the chart, color-coded by price action (Green/Red).
- **🎨 Professional Dark Mode:** A sleek, "Bloomberg Terminal"-style dark UI designed for long hours of analysis.
- **📥 Data Export:** One-click download of historical price data in CSV format.
- **📱 Responsive Layout:** Optimized for both desktop and mobile viewing.

## 🛠️ Tech Stack

- **Core Framework:** Streamlit
- **Data Processing:** Pandas
- **Data Source:** yfinance (Yahoo Finance API)
- **Visualization:** Plotly Graph Objects
